# RSVP for the user

The browser uses the user's real, signed-in browser profile, so most event
sites are already logged in. Never ask for, type, or store a password; if a
site needs a login the profile doesn't have, tell the user and stop.

1. Open the event link with the browser tools and read the page: event name,
   date/time, place, and what the RSVP form asks for.
2. Fill what you can from memory (name, email) — never invent answers to
   questions about the user (dietary needs, plus-ones, company) you don't
   know; ask.
3. Before the final submit/RSVP click, text the user ONE line and wait:
   "RSVP yes to <event> on <date> at <time>? (<anything you filled in>)".
   Only an explicit yes counts. This is the user's own confirmation step —
   do it every time, even if they asked you to RSVP.
4. Click submit, then confirm what the page shows (confirmation text or
   email). Add the event to the calendar with the vertus-calendar skill.
5. Reply: "Done — you're going to <event>, <date> <time>. Added to your calendar."
