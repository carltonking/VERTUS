Everything Alfred can do
🧠

Context-aware AI

Reads your frontmost app, selected text, and browser URL. Every answer is in context.

📋

Clipboard history

Last 50 clipboard items always one shortcut away. Tap to paste back into any app.

🔍

File + app search

Type /query to search files. Type any app name to launch it instantly.

🎨

Image generation

Type /img prompt to generate with DALL-E 3. Saved to your drive.

⚡

Instant calculator

Math expressions and unit conversions answered instantly — no AI round-trip.

🔔

Smart notifications

Meeting prep 30 min before events. Break reminders after 90 min in video calls.

🎙️

Voice wake word

Say "Alfred" and the bar opens. No hands needed.

📌

Pin responses

Star any answer. Browse your pinned responses anytime with > Pinned.

🌙

System controls

Dark mode, mute, Wi-Fi, brightness — all from the actions palette.

⌘⇧J

Press anywhere to open Alfred

How to install
1

Download

Click the Download button above. You'll get Alfred-v1.0.zip.

2

Unzip and run installer

Open the zip, then double-click Install Alfred.command. It handles everything.

3

Enter your API key

The installer will ask for your Anthropic API key. Paste it in — takes 10 seconds.

4

Press ⌘⇧J

Alfred is in your menu bar. Press ⌘⇧J anywhere to open the bar.
